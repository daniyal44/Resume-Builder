## 🚀 Featured project — OwnResume

A free resume builder with **no account, no upload and no watermark**. Eight ATS-friendly
templates, a live A4 preview, PDF import and one-click export — everything stored in the
visitor's own browser.

[![Repo](https://img.shields.io/badge/daniyal44%2FResume--Builder-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/daniyal44/Resume-Builder)
[![Live](https://img.shields.io/badge/Try_it-free-22c55e?style=for-the-badge)](https://getownresume.netlify.app/)

- **Stack:** React 19 · TypeScript · Vite · Tailwind CSS v4 · pdfjs-dist
- **SEO / AEO / GEO:** JSON-LD `@graph`, crawlable static guide pages, `llms.txt`, AI-crawler policy
- **Quality:** ESLint clean, CI on Node 20 + 22, fully responsive from 320 px
